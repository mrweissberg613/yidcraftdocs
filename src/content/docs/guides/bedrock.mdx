YidCraft is on Bedrock Edition too. Play from a phone, a tablet, an Xbox, a PlayStation, a Nintendo Switch or Windows Bedrock, on the same world as the Java players.

## How to join

In Minecraft, go to **Play**, then **Servers**, then **Add Server**:

| | |
|---|---|
| **Server Address** | `yidcraft.jewishgaming.net` |
| **Port** | `21702` |

Our port is **21702**. The usual Bedrock port, 19132, will not find us.

Save the server and join. On the server, Bedrock names have a dot in front, like `.YourName`.

## Linking Discord

Same as on Java. The first time you join, a code appears on your screen. Go to the **Link Account** panel in our Discord, click **Link Account**, and enter the code. Join again and you are in.

## Playing on both Java and Bedrock

You have two choices.

**Link your Java and Bedrock accounts.** We strongly recommend it. Join `link.geysermc.org` once from Java and once from Bedrock, type `/linkaccount`, and follow what it tells you. After that, joining from Bedrock is joining as your Java account: one inventory, one set of pets and quests, one purse of Shekels. One player, one account.

**Keep two separate accounts.** This is allowed, but each account starts from nothing and links to Discord on its own.

:::caution[Double rewards]
Using two accounts to collect the same rewards twice (daily rewards, quests, boss drops, anything like them) is abuse, and it can get both accounts banned.
:::

If you only play on Java, or only on Bedrock, none of this affects you. Join and play.

## Skins

Your Bedrock skin shows to Java players too. The first time you join it can take a little while to appear for them, and it is remembered after that. Bedrock-only extras, like 3D capes and Persona clothing, are flattened onto a normal skin, so they can look a bit different on Java. Linked accounts wear the Java skin on both editions.

## What looks different

Some menus open as Bedrock windows instead of chests: `/pets`, the [Boss Journal](/features/bosses/), conversations with the people of spawn, and anything that would be a clickable message in Java chat. They do the same things.

To skip a cutscene on Bedrock, sneak twice quickly.

Something broken, missing or looking wrong? Tell us in the help channel on Discord.
