:::danger[Connection Issues]
If you cannot join on Java, check that you are on version **1.21.11** or newer and that the server is online.
:::

## Java

```text
yidcraft.jewishgaming.net
```

1. Open Minecraft and go to **Multiplayer**.
2. Choose **Add Server** or **Direct Connection**.
3. Paste the address above and join.

## Bedrock

Phone, tablet, Xbox, PlayStation, Switch or Windows Bedrock. Go to **Play**, then **Servers**, then **Add Server**:

| | |
|---|---|
| **Server Address** | `yidcraft.jewishgaming.net` |
| **Port** | `21702` |

The port is 21702, not the usual 19132. More about Bedrock, including one account across both editions, is on [Playing on Bedrock](/guides/bedrock/).

## Your first join

A code appears on your screen. Enter it in the **Link Account** panel in our Discord, then join again. Then find Reb Tuvia by the fountain at spawn for [the tutorial](/guides/tutorial/).
