<Aside type="tip" title="Client-Side Mods">
YidCraft allows many client-side mods that improve your gameplay experience, provided they **do not give an unfair advantage** over other players.
</Aside>

## General Rule

A mod is generally allowed if it:

- Only changes how **you** see or interact with the game
- Does **not** automate gameplay
- Does **not** reveal hidden information
- Does **not** provide an unfair PvP or survival advantage

If you are unsure whether a mod is allowed, ask a staff member before using it.

---

## Minimap Mods

Minimap mods are allowed as long as all unfair features are disabled.

The following features **must be disabled**:

- Entity Radar
- Player Radar
- Mob Radar
- Cave Maps
- Underground Mode
- Ore Detection
- Structure Detection

<Aside type="caution" title="Minimap Rules">
Using radar features, cave maps, or any feature that reveals hidden information is considered cheating.
</Aside>

---

## Replay Mod & Flashback

Replay Mod and Flashback are allowed for videos and screenshots.

They may not be used to:

- Look through walls
- Scout bases
- Find hidden players
- Gain information unavailable during normal gameplay

---

## Freecam

Freecam is allowed only for screenshots and cinematic recordings.

Freecam may not be used to:

- Look through walls
- Scout underground areas
- Find hidden players
- Locate bases
- Gain an unfair advantage

<Aside type="caution" title="Freecam Restrictions">
Using Freecam for gameplay advantages is not allowed.
</Aside>

---

## Inventory Management Mods

Inventory sorting mods are allowed.

Mods that:

- Automatically move items during combat
- Automate gameplay actions
- Give an unfair advantage

are not allowed.

# Configuring Xaero's Minimap

Before joining YidCraft, Xaero's Minimap must be configured correctly.

<Aside type="caution" title="Required Settings">
Some Xaero's Minimap features provide unfair advantages and must be disabled before playing on YidCraft.
</Aside>

---

## Making Xaero's Minimap Fair Play

To use Xaero's Minimap on YidCraft, disable any features that provide unfair advantages, such as locating players, mobs, or underground areas.

Follow these steps to configure Xaero's Minimap correctly.

---

## Open Xaero's Minimap Settings

<Steps>

1. Join YidCraft.

2. Press **Y** to open Xaero's Minimap settings.

3. Select the settings menu.

</Steps>

---

## Disable Entity Radar

Entity Radar can reveal the location of players and mobs, which is not allowed.

<Steps>

1. Open **Entity Radar Settings**.

2. Find **Display Radar**.

3. Set **Display Radar** to **OFF**.

</Steps>

The following features must remain disabled:

- Player Radar
- Mob Radar
- Entity Radar

---

## Disable Cave Mode

Cave Mode can reveal underground areas and hidden locations.

<Steps>

1. Open the Xaero's Minimap settings menu.

2. Select **Block Map Settings**.

3. Find **Cave Mode**.

4. Set **Cave Mode** to **OFF**.

</Steps>

Cave maps and underground mapping are not allowed because they reveal information unavailable during normal gameplay.

---

## Allowed Xaero's Minimap Features

The following features are allowed:

- Waypoints
- Death Waypoints
- Surface Minimap
- Coordinates
- Biome Display
- Compass
- Zoom Levels

---

## Not Allowed Xaero's Minimap Features

The following features are not allowed:

- Player Radar
- Mob Radar
- Entity Radar
- Cave Mode
- Underground Maps
- Ore Detection
- Structure Detection

<Aside type="tip" title="Configuration Complete">
Once **Display Radar** and **Cave Mode** are disabled, Xaero's Minimap is configured correctly for YidCraft.
</Aside>

---
